# Icalkit

An unreleased Rust library for parsing, editing, and querying iCalendar data.

## Installation

```sh
git clone https://github.com/P4suta/icalkit.git
cd icalkit
mise install
```

## Usage

```sh
mise x -- cargo run --locked -p icalkit --example golden_path
```
